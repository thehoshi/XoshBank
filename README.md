# XoshBank

XoshBank is a desktop banking management system developed with C# and WPF.

The application simulates core banking operations and includes structured architecture with entities, repositories, and business logic layers.

## Features

- Customer account management
- Bank card system
- ATM and branch models
- Loan and payment template management
- Data handling with repository pattern
- Structured desktop interface

## Technologies Used

- C#
- WPF
- .NET
- SQL
- Repository Pattern

## Project Structure

- XoshBank.Core — business logic and data models
- Entities — banking system entities
- Repositories — data access layer
- Interfaces — abstraction layer

## Implemented Concepts

- Object-Oriented Programming
- Repository Pattern
- Layered Architecture
- CRUD Operations
- Data Management

## Future Improvements

- Authentication system
